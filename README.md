# Wireless corne keyboard ZMK firmware config

This is my config for a [ZMK](https://zmk.dev/) firemware for a wireless 6-column corne split keyboard
with a nice!view displays.

My personal one was bought on [typeractive](https://typeractive.xyz/pages/build#corne_choc).

It's a usual QWERTY-layout. The main difference between the default layout, and
what this config uses:

- I'm used to caps-lock being remapped to esc, so the leftmost middle-row key
  (left to A) is ESC for me instead of CTRL.
- Usually ESC is on the rightmost low row, but for me this is a right shift
  (I try to stick to correct left/right shift combinations)
- While the leftmost thumb key is SUPER/GUI key by default, for me it brings
  back control (removed)
- tapdance on middle left thumb key, to bring back SUPER/GUI key (single tap = LWT, double = GUI)
- On raised layer '~' moved from "SHIFT" key to "A" (as I want my SHIFTs to be
  consistent)
